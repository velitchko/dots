# Theme

There is one theme pipeline and one source of truth: **`~/.config/hypr/scripts/theme.sh`**.

```
wallpaper ──matugen──▶ Material roles (primary, secondary, tertiary, containers, on-*, error, outline…)
mode (dark/light) ───▶ fixed base: pitch black #000000 / eggshell #F0EAD6
                        └──▶ theme.sh writes every consumer below
```

Run it from the island (quick settings → **Dark mode** switch, wallpaper strip, `CTRL+SUPER+T`), with `CTRL+SUPER+SHIFT+D`, or directly:

```sh
~/.config/hypr/scripts/theme.sh mode dark|light|toggle
~/.config/hypr/scripts/theme.sh wallpaper ~/Pictures/Wallpapers/foo.png
~/.config/hypr/scripts/theme.sh apply        # regenerate from saved state
```

## What it themes

| Consumer | Output | Reload |
| --- | --- | --- |
| Island (Quickshell) | `~/.local/state/kessel/theme/colors.json` | live (IPC) |
| Lock screen, SDDM | same `colors.json` (SDDM copies it on `sddm-theme.sh install`) | next lock / install |
| Hyprland borders | `…/theme/hyprland.lua` | `hyprctl reload` |
| kitty (16 colors) → fish, Starship | `…/theme/kitty.conf` (included by `kitty.conf`) | live (`kitten @ set-colors` over a private socket in `$XDG_RUNTIME_DIR`) |
| Starship pills | `…/theme/starship.toml` (palette `kessel`; fish sets `STARSHIP_CONFIG`) | next prompt |
| fish syntax | universal `fish_color_*` variables | live |
| fuzzel | `…/theme/fuzzel.ini` (included) | next launch |
| Qt apps (Dolphin…) | `~/.config/qt6ct/colors/Kessel.conf` + qt6ct keys | next launch |
| KDE apps | `~/.local/share/color-schemes/Kessel.colors`, `kdeglobals`, `dolphinrc` | next launch |
| GTK 3 / GTK 4 / libadwaita (OmniGlyph…) | `~/.config/gtk-{3,4}.0/gtk.css` + gsettings color-scheme | next launch (OmniGlyph is restarted) |
| btop | `~/.config/btop/themes/kessel.theme` | next launch |
| yazi | `~/.config/yazi/theme.toml` | next launch |
| Neovim | `…/theme/nvim.json` (base16 palette, applied by `lua/kessel/theme.lua` with mini.base16) | live (file watcher) |
| Firefox | follows GTK (keep Firefox's theme on *System theme — auto*); needs `adw-gtk-theme` so GTK 3 uses `gtk.css` | restart Firefox |
| OnlyOffice | `~/.config/onlyoffice/DesktopEditors.conf`: a built-in theme matching light/dark (your own choice is kept if it matches); title bar set to *system*. Custom theme files only recolor its tab strip, so none is shipped | restart OnlyOffice |

Generated files start with *"generated by theme.sh"*. Remove that line from `gtk.css` or `yazi/theme.toml` only if you deliberately want to take ownership of the file. Otherwise, change `theme.sh`, not its output.

Terminal colors: blue/magenta/cyan are the scheme's primary/tertiary/secondary, red is the scheme's error, and green/yellow are fixed hues *harmonized* 25% toward the primary (matugen's own base16 output isn't usable).

## Fonts

**JetBrainsMono Nerd Font** everywhere (UI 11, mono 12). fontconfig maps `sans-serif`/`monospace`/`serif` to it, with **Noto Color Emoji** as the emoji fallback. Font names are set in: `kitty.conf`, `fuzzel.ini`, `dunstrc`, `Theme.qml`, the lock screen's `Style.qml`, `hyprlock.conf`, `gtk-*/settings.ini`, qt6ct and gsettings (via `theme.sh` / the installer).

## Adding a new app

Add a block to `apply()` in `theme.sh` that writes only the application's keys you own, using the variables already defined there (`$BG $TEXT $P $ONP $PC $T $ERR …`). Then add the application to the table above.
